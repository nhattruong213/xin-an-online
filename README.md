# xin-an-online

Website dựng bằng Next.js từ giao diện "Xin Một Bữa Cơm".

## Chạy trên máy

```bash
npm install
npm run dev
```

Mở http://localhost:3000. Lệnh `dev` build và phục vụ bản tĩnh để tránh lỗi giới hạn file watcher trên máy cục bộ. Khi sửa mã nguồn, chạy lại lệnh để cập nhật trang.

Thông tin chuyển khoản nằm trong `lib/payment.ts`; ảnh QR tương ứng nằm tại `public/payment-qr.png`.
